**Full description** (4000 char limit)

```
Morpho converts documents entirely on your phone. Not "encrypted in transit" —
never sent at all. The app has no internet permission, so it has no way to
upload your documents even if it wanted to. You can check that yourself in the
app's permission list before you trust it with anything.

WHAT IT CONVERTS
• PDF → Word (.docx)
• Word (.docx) → Markdown
• Text, Markdown and Word → PDF
• Scanned PDFs → Word, using on-device OCR

BUILT FOR ARABIC, NOT PATCHED FOR IT
Most converters mangle Arabic: letters disconnect, words reverse, numbers jump
to the wrong side of a sentence. Morpho runs the full Unicode bidirectional
algorithm over every document and marks direction per run of text, so an
English product name inside an Arabic paragraph lands exactly where it belongs.
The interface is fully right-to-left in Arabic, and you can set the app's
language independently of your phone's.

Arabic, English, French, Spanish and German — interface and OCR alike.

IT TELLS YOU WHEN IT IS GUESSING
A PDF that carries its own structure can be read exactly. A PDF that doesn't
has to be reconstructed from where the letters sit on the page, and a scan has
to be read by OCR. Those are guesses, and Morpho says so: after every
conversion you can open the fidelity report and see each part of the document
with how it was read — exactly, from the PDF's tags, reconstructed, or
recognized. Anything the app is unsure about is listed first.

AND YOU CAN FIX IT BEFORE YOU SEND IT
If a heading came through as ordinary text, correct it right there and save the
file again. Every other converter makes you discover that after you have
already emailed it.

ALSO
• Share a document to Morpho from any app, or open one with it
• Save anywhere through your phone's own file picker
• Print, or export a real PDF file
• No ads, no account, no watermark, no sign-in
• Works with no network connection, on a plane, anywhere

WHAT IT DOES NOT DO
It does not collect anything. There is no analytics, no crash reporting on
document contents, no account, and no server — because there is no network
permission at all.
```
